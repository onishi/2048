2048 AI Guide

遊び方

数字を重ねて2048を目指しながら、4種類のAIの考え方や強さを試せます。

基本操作 AIで遊ぶ 設定 分析
01

基本操作

同じ数字のタイルを重ねると、2つが合体してスコアが増えます。動かせる場所がなくなるまでに2048のタイルを作りましょう。

  • PC: 矢印キーで盤面を上下左右に動かします。
  • スマートフォン: 盤面を動かしたい方向へスワイプします。
  • Undo: 直前の手を取り消します。
  • Reset: 現在の設定で新しいゲームを始めます。
02

AIで遊ぶ

AI Move はAIが選んだ次の1手だけを実行し、判断材料も表示します。Start AI はゲーム終了まで自動で進め、もう一度押すと一時停止します。

Random

有効な手からランダムに選びます。比較の基準に向いています。

Greedy

次の盤面が最も良くなる1手を選ぶ、軽快なAIです。

Expectimax

先の展開と新しいタイルの出現確率を読んで選びます。

Neural

学習済みモデルで素早く判断します。4×4・開始タイル2専用です。

03

AIとゲームの設定

Depth
Expectimaxが何手先まで読むかを設定します。大きいほど強くなる可能性がありますが、計算時間も増えます。迷ったらAutoがおすすめです。
Speed
自動プレイの速度です。Maximumではアニメーションを省略して最速で進めます。
Size / Start
盤面サイズと開始タイルを変更します。変更すると新しいゲームが始まります。
Theme
Classic、Sci-Fi、Natureから見た目を選べます。選択は次回も引き継がれます。
04

AIを分析する

Benchmark / Compare AIs を開き、試行回数を指定して実行します。

  • Run Benchmark: 現在選択中のAIを複数回走らせ、平均スコアや最高タイルを集計します。
  • Compare AIs: 利用可能なAIを同じ条件で走らせ、結果を一覧で比較します。

試行回数やDepthが大きいほど完了まで時間がかかります。まずは少ない回数で試すのがおすすめです。
